# Quadcopter Drone Control Application – Version 2

A Flutter (Dart) mobile application for controlling a quadcopter drone. This is the second version of the app, with an improved structure over Version 1.

## About the Project

This project provides a mobile interface for controlling and interacting with a quadcopter drone.

The app is built with Flutter and Dart, so the same code base can run on multiple platforms.

- Flutter SDK

- Quadcopter Drone with a Flight Controller
- Communication Module (for example Wi-Fi / Bluetooth)

## Working Principle

1. The user opens the application on a mobile device.
2. The app connects to the drone's communication module.
3. Control inputs from the interface are converted into commands.
4. Commands are sent to the drone's flight controller.
5. The drone responds to the commands in real time.

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/sakthi960/QUADCOPTER-DRONE-CONTROL-APPLICATION-VERSION-2.git
```

2. Install the Flutter SDK.
3. Open the project in VS Code or Android Studio.
4. Install dependencies.

```bash
flutter pub get
```

5. Connect a device or start an emulator.
6. Run the application.

```bash
flutter run
```

**Note:** Refer to the actual implementation for the drone communication method, command format and hardware requirements.
